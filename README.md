# Cleaning Service Website

A modern and responsive website built for a cleaning service business to improve online presence and convert visitors into customers.

## 🚀 Features
- Fully responsive design (mobile-friendly)
- Clean and modern UI
- Services page
- Pricing table
- Smooth animations and transitions
- Contact/lead capture section

## 🛠️ Built With
- HTML
- CSS
- JavaScript

## 🎯 Project Goal
The goal of this project is to build a website that helps a cleaning business:
- Increase visibility online
- Build credibility
- Convert visitors into paying customers.
